Jira is tool for tracking issues, tasks and progress in software projects.

Core use cases:

Bug tracking

Task tracking

Project planning

Agile development

What a Project Is: Container for related work items.

Project templates (Scrum, Kanban, Work Management).

Scrum: uses sprints and iterations

Kanban: continuous flow

Work Management: basic task tracking


Key terms:

Issues: The basic unit of work.

Types:

Task: Work item 

Bug: Defect

Story: user functionality

Epic: Big work that convert into task or stoies.

Epic = Big Goal

Stories / Tasks = Small steps to reach that goal

Epic: User Authentication System

Inside this epic, you might have:

Create login API

Create registration API

Design login page UI

Add password reset feature

Add email verification

Write unit tests

Epic 1 → Phase 1

Epic 2 → Phase 2

Epic 3 → Phase 3

You open the epic and show:

12 tasks total

9 completed

3 remaining


Project
└── Epic (Big phase)
  └── Story / Task (Work item)
    └── Subtask (Optional smaller step)
